# Ellinika – Griechisch lernen ☦

Lern-App im Stil von Duolingo für Alltagsgriechisch und die Sprache der orthodoxen Liturgie (Griechisch · Kirchenslawisch · Deutsch).

- Lernpfad mit Lektionen, Kronen, XP, Tagesziel und Streak
- Übungen: Bedeutung wählen, Übersetzen, Hören, Sätze bauen, Paare finden
- Lautschrift für deutsche Sprecher und Vorlesen (Web Speech API, Stimme el-GR)
- Texte: Vaterunser und liturgische Rufe, Wort für Wort anhörbar
- Import neuer Begriffe als JSON (z. B. aus Notion)

Alles läuft im Browser, der Fortschritt wird lokal gespeichert.

Live: https://andrel98.github.io/ellinika/
